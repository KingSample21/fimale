# Site da Firma LE

Site estático responsivo para a Firma LE, com foco principal em **montagem e instalação de câmeras de vigilância (CCTV)** e apresentação secundária dos outros sectores.

## Conteúdo
- `index.html` — conteúdo, metadados SEO, dados estruturados e contactos.
- `styles.css` — identidade visual e adaptação a telemóveis.
- `script.js` — menu móvel, ano automático e perguntas frequentes.
- `robots.txt` e `sitemap.xml` — preparação básica para motores de pesquisa.
- `assets/` — favicon e imagem de partilha social em SVG.

## Antes de publicar
1. Confirme se o endereço `https://firmale.github.io/` está disponível e se corresponde ao utilizador/organização GitHub correto.
2. Se o endereço final for diferente, substitua `https://firmale.github.io/` em `index.html`, `robots.txt` e `sitemap.xml` pelo URL real. Atualize também o URL da imagem social.
3. Confirme os serviços realmente disponíveis, as províncias atendidas e os dados comerciais da Firma LE. O texto evita prometer serviços, garantias, preços ou resultados não confirmados.
4. Confirme que o WhatsApp `+244 927 470 585` está ativo.
5. Abra `index.html` no navegador para testar o site antes de publicar.

## Publicar com GitHub Pages
1. Crie/entre na conta GitHub pretendida.
2. Crie um repositório chamado `firmale` (o endereço `firmale.github.io` depende do nome de utilizador/organização e da configuração de Pages; não está garantido).
3. Envie os ficheiros deste projeto para a raiz do repositório.
4. Nas configurações do repositório, abra **Pages** e escolha a publicação a partir do branch principal e da pasta raiz (`/root`).
5. Aguarde a publicação e teste o endereço público em telemóvel e computador.

## SEO depois de publicar
1. Adicione o site ao Google Search Console.
2. Verifique a propriedade do domínio/URL conforme as opções apresentadas pelo Google.
3. Envie `https://SEU-ENDERECO/sitemap.xml` no Search Console.
4. Confirme a indexação e corrija eventuais avisos.
5. Crie/atualize um Perfil de Empresa no Google apenas se a empresa cumprir os requisitos e puder confirmar os dados reais do negócio.

## Notas
- O site não usa fotografias de clientes ou instalações reais. A imagem de destaque é uma ilustração CSS. Substitua por fotografias próprias e autorizadas quando existirem.
- Não foram incluídos endereço físico, horário, preços, certificações, testemunhos ou garantias porque esses dados não foram confirmados.
- O texto do site usa linguagem comercial natural, mas deve ser revisto pela Firma LE para refletir com precisão os serviços e a forma de atendimento.
